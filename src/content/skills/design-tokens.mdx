## What it does

Manages design tokens — the named source of truth for colors, spacing, typography, and shadows — using the W3C Design Tokens Community Group (DTCG) 2025.10 standard, with a dependency-free Python core. From one canonical `*.tokens.json` it compiles CSS custom properties, a Google-Labs `DESIGN.md` (the format AI coding agents read), and a standalone HTML preview. It also imports an existing CSS file's `:root` variables straight into DTCG, preserving their names.

## Key features

- **Standard, not invented** — speaks DTCG 2025.10 throughout; output is plain DTCG so Figma, Style Dictionary, and Tokens Studio consume it directly.
- **Two formats, one source** — emits CSS variables for code *and* a linter-clean `DESIGN.md` for Claude Code / Cursor / v0, both resolved from the same tokens.
- **Global base + project overrides** — layer a project's deltas over a shared brand base; aliases resolve deterministically with cycle detection.
- **CSS import door** — pull an existing stylesheet's custom properties into DTCG without hand-translation, names preserved for clean round-trips.
- **Visual preview** — a standalone HTML swatch page (color chips, type specimens, spacing, rounded, shadow) to see a token set at a glance.

## When to use

When you want to define a brand or design system once — globally or per project — and have it stay consistent across code, AI-generated UI, and collaborators, instead of hardcoding hex values and fonts in scattered places.
